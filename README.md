# سامانه مدیریت بارگیری Cargo

## معرفی
سامانه مدیریت بارگیری Cargo یک نرم‌افزار جامع برای مدیریت و نظارت بر عملیات بارگیری در اسکله‌ها و انبارها است. این سامانه با استفاده از فناوری‌های مدرن اندروید و Jetpack Compose توسعه یافته و امکان مدیریت کامل فرآیند بارگیری از ثبت حواله تا خروج محموله را فراهم می‌کند.

## قابلیت‌های اصلی

### مدیریت بارگیری
- ثبت و مدیریت حواله‌های ورود و خروج
- اسکن قبض باسکول با استفاده از دوربین
- ثبت اطلاعات دقیق وزن خالص، کسری و اضافه بار
- پشتیبانی از عملیات چندکاربره با سطوح دسترسی متفاوت
- مدیریت خودکار محدودیت‌های درصد کوتاژ
- امکان جستجو و فیلتر حواله‌ها بر اساس معیارهای مختلف

### پایش لحظه‌ای
- نمایش آمار بارگیری به صورت لحظه‌ای
- گزارش عملکرد شیفت‌های کاری
- نمایش وضعیت انبارها و کوتاژها
- پایش عملکرد شرکت‌های باربری
- تحلیل ساعات اوج کاری و الگوهای ترافیکی

### تحلیل و گزارش‌گیری
- گزارش‌های تحلیلی جامع از عملکرد سیستم
- تحلیل کارایی انبارها و شرکت‌های باربری
- امکان خروجی گزارش‌ها در قالب PDF
- نمودارها و شاخص‌های کلیدی عملکرد
- پیش‌بینی زمان تکمیل کوتاژها

### سیستم پیام‌رسانی
- ارسال پیام بین کاربران سیستم
- اعلان‌های خودکار برای رویدادهای مهم
- هشدار برای تجاوز از محدودیت‌های تعیین شده
- امکان ارسال پیام گروهی به کاربران

## ویژگی‌های فنی

### معماری و تکنولوژی
- توسعه‌یافته با Kotlin و Jetpack Compose
- معماری MVVM برای جداسازی لایه‌های برنامه
- استفاده از Coroutines و Flow برای عملیات‌های ناهمگام
- مدیریت state با StateFlow و MutableStateFlow
- انیمیشن‌های روان با Compose Animation APIs

### رابط کاربری
- طراحی Material Design 3
- پشتیبانی از حالت شب و روز
- رابط کاربری ریسپانسیو و انعطاف‌پذیر
- انیمیشن‌های روان و تعاملی
- پشتیبانی کامل از راست به چپ (RTL)

### کلاس‌های اصلی

#### CargoViewModel
مدیریت منطق اصلی عملیات بارگیری:
```kotlin
class CargoViewModel(
    private val repository: ReportsRepository,
    private val userPreferencesManager: UserPreferencesManager
) : ViewModel()
```

#### ReportsViewModel
مدیریت گزارش‌ها و تحلیل‌ها:
```kotlin
class ReportsViewModel(
    private val repository: ReportsRepository,
    application: Application
) : AndroidViewModel(application)
```
